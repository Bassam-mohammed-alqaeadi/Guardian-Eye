# تدفق النظام (System Flow)

يوضح هذا المستند المراحل التتابعية لتشغيل النظام والتفاعل بين المستخدم والأجهزة المختلفة.

## 1. دورة التثبيت والبدء لأول مرة
عند تثبيت التطبيق لأول مرة، يمر المستخدم عبر تدفق هادئ يبدأ بشاشة الترحيب، ثم إنشاء أو انضمام للعائلة، مروراً بتحديد الهوية والأدوار، وصولاً إلى منح الصلاحيات بشكل تدريجي ومبرر.

## 2. دورة المصادقة والأمان
يتم الاعتماد على نظام مصادقة مركزي يربط حساب الأب أو الطفل بالعائلة المعتمدة عبر رموز دعوة مشفرة وآمنة تمنع انضمام أي مستخدم غير مصرح له.

## 3. تدفق تنبيهات الذكاء الاصطناعي
يقوم محرك الذكاء الاصطناعي المحلي والسحابي بتحليل الأحداث، وتصنيف المخاطر، وتقديم تفسيرات بشرية واضحة للوالدين لتمكينهم من اتخاذ القرار التربوي المناسب في الوقت المناسب.
