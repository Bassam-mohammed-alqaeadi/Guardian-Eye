# Guardian AI — منصة الأمان العائلي الذكية

> **شعار المنصة:** «حماية العائلة بدون تدمير الثقة»

## نظرة عامة
تعتبر **Guardian AI** منصة متقدمة لأمان العائلة، الرفاهية الرقمية، الرقابة الأبوية الإيجابية، وإدارة الأسرة مدعومة بالذكاء الاصطناعي. تم تصميم المنصة لتكون أكثر ذكاءً، وعاطفية، ووعياً بالخصوصية من تطبيقات المراقبة التقليدية.

## هيكل المشروع (Clean Architecture)
يتبع المشروع بنية نظيفة وقابلة للتوسع:
- `lib/core/`: ثوابت، أنظمة التصميم (Theme)، التعريب (Localization)، وحقن التبعيات (DI).
- `lib/domain/`: كيانات الأعمال (Entities)، واجهات المستودعات (Repositories)، وحالات الاستخدام (Use Cases).
- `lib/data/`: النماذج (Models)، مستودعات البيانات، ومصادر البيانات.
- `lib/presentation/`: واجهات المستخدم (Screens)، المكونات (Widgets)، وإدارة الحالة (Riverpod Providers).

## التقنيات المستخدمة
- **الإطار البرمجي:** Flutter (Dart)
- **إدارة الحالة:** Riverpod
- **التوجيه:** GoRouter
- **التعريب:** دعم كامل للغتين العربية والإنجليزية مع اتجاه RTL و LTR.
- **التصميم:** تصميم حديث، هادئ، وموثوق يدعم الوضعين الفاتح والداكن (Light/Dark Mode).
