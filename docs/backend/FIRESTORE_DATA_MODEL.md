# Firestore Data Model — Guardian Eye Pro

## Ownership model

The authenticated Firebase UID is the server-enforced identity. A family is owned by its `ownerUid`; membership documents define roles and may bind a human member to a Firebase UID. A device is a family child resource with `ownerUid`, `memberId`, `memberUid`, `role`, and `status`. Mobile clients may write only resources permitted by rules; privileged notification fanout is server-side.

| Collection / path | Required fields | Writer | Reader | Purpose |
|---|---|---|---|---|
| `users/{uid}` | `uid`, `displayName`, `createdAt`, `updatedAt` | Self for limited profile fields; backend for role bindings | Self | Account profile only; no family authority derives from this document. |
| `families/{familyId}` | `familyId`, `name`, `ownerUid`, `primaryParentId`, `status`, timestamps, `idempotencyKey` | Primary parent during creation | Authorized family member | Family root and immutable ownership anchor. |
| `families/{familyId}/members/{memberId}` | `memberId`, `memberUid?`, `displayName`, `role`, timestamps | Primary parent or privileged backend | Family member | Family roles; a client may never self-escalate. |
| `families/{familyId}/children/{childId}` | `childId`, `memberId`, `status`, timestamps | Authorized parent | Authorized parent; child only if explicitly allowed | Child-specific profile fields separated from parent account. |
| `families/{familyId}/devices/{deviceId}` | `deviceId`, `memberId`, `memberUid`, `ownerUid`, `role`, `status`, timestamps | Authorized parent during enrollment/revoke | Family member by role | Active/revoked binding used by protected client writes. |
| `families/{familyId}/device_pairings/{pairingId}` | `pairingId`, `targetMemberId`, `requestedRole`, `status`, `expiresAt`, timestamps | Authorized parent / backend | Authorized parent | Pairing metadata only; never store raw pairing code. |
| `families/{familyId}/policies/{policyId}` | `policyId`, `priority`, `enabled`, rule/schedule fields, version, timestamps | Authorized parent | Family member as policy permits | Policy source; merge/update requires explicit conflict policy. |
| `families/{familyId}/incidents/{incidentId}` | `incidentId`, `deviceId`, `category`, `severity`, `status`, `observedAt`, `modelVersion`, timestamps | Active owned device / backend | Authorized parent | Safety incident without raw evidence payload by default. |
| `families/{familyId}/sos/{sosId}` | `sosId`, `deviceId`, `status`, location precision fields, timestamps | Active owned device / backend | Authorized parent | SOS record; queue/sync/notified/acknowledged stay distinct. |
| `families/{familyId}/locations/{locationId}` | `locationId`, `deviceId`, coordinates, accuracy, `capturedAt` | Active owned device | Authorized parent | Consent-gated location updates. |
| `families/{familyId}/geofences/{geofenceId}` | boundary, policy, version, status, timestamps | Authorized parent | Authorized parent/device as permitted | Geofence configuration. |
| `families/{familyId}/notification_events/{eventId}` | event target, type, request state, timestamps | Privileged backend only | Authorized parent | Requested/accepted/delivered/acknowledged state; direct client writes denied. |
| `families/{familyId}/sync_metadata/{eventId}` | event ID, operation, author UID, idempotency key, status, timestamps | Authenticated authorized client | Authorized parent | Audit/idempotency metadata, not a substitute for business documents. |
| `families/{familyId}/devices/{deviceId}/notification_tokens/{tokenId}` | device ID, user UID, FCM token, platform, status, timestamps | Active device subject to rules | Privileged backend only | Push target registration. Tokens must never be exposed to unrelated members. |

Every business write contains a family identifier, actor identity from server auth, status where lifecycle exists, and a deterministic idempotency key. Server timestamps are generated by Firestore/Cloud Functions when the backend is configured.
