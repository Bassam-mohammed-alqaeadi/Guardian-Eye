## 1. الملخص التنفيذي

## 3. البنية التقنية

| الطبقة | التفاصيل |
|---|---|
| UI | Flutter 3.35.6، Material 3، Riverpod + hooks_riverpod، GoRouter (42 مسار + ShellRoute بتنقل سفلي 5 تبويبات) |
| الحالة | 1,866 سطراً من المزودين (providers) في `lib/application/` |
| التخزين المحلي | SQLite v16 (sqflite + sqflite_common_ffi للاختبار)، offline-first مع outbox |
| الواجهة السحابية | Firebase Auth + Firestore بعقود حقيقية في `firestore_contracts.dart` (FS-001: 5 حالات، FS-002: 6 حالات) |
| المزامنة | SyncCoordinator + OutboxSyncExecutor (تجربة فورية + إعادة جدولة) |
| الترجمة | AppLocalizations — عربية (RTL) + إنجليزية، ~1,143 مفتاح |
| التصاميم المولدة | شعار التطبيق + 4 صور onboarding مدمجة في الشاشة الرئيسية وشاشات LO-010 وWF-001 + خلفية إطلاق كحلية |

## 4. حالات التحقق (Validation)

### A. التحقق الهيدلس (flutter_tester) — تم جزئياً
- تم بناء harness يُقلع التطبيق الحقيقي (`GuardianApp`) ويتنقل عبر 42 مساراً باللغتين مع لقطات شاشة 1080×2400.
- **النتيجة:** جميع الـ 274 اختبار أساس أخضر. harness التقط لقطات حقيقية (لوحة العائلة بالعربية والإنجليزية، نموذج إنشاء الجدار الجغرافي) وأثبت أن جميع المسارات تبني شاشات فعلية.
- **القيد:** تكرار إعادة بناء شجرة التطبيق الكاملة في flutter_tester داخل هذه البيئة يتوقف (software rendering) — هذا قيد معروف في أداة flutter_tester نفسها ولا يعادل اختبار Android حقيقي.

### B. التحقق على جهاز Android حقيقي — لم يتم
لا يوجد في هذه الجلسة جهاز Android حقيقي أو سحابة اختبار متاحة. APK قيد البناء الآن (انظر القسم 5).
