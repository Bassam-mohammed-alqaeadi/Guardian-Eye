## 1. الهدف والقيمة

FS-009 هي المرحلة التي تستهلك كل البيانات التي سجلتها المراحل السابقة (FS-001 الموقع والأسوار، FS-002 فلترة الويب، FS-003 التطبيقات، FS-004 المراقبة، FS-005 الأنماط المخصصة، FS-006 التنبيهات SOS، FS-015 الأجهزة) وتحوّلها إلى **تقارير عائلية صادقة** تُعرض داخل التطبيق وتُصدَّر إلى ملفات **PDF** و **CSV** يمكن مشاركتها مع الأخصائيين أو حفظها كأرشيف أسري.

المبدأ الحاوي لكل هذه المرحلة هو **الصدق التام (Honest Reporting)**: لا اختراع أرقام، ولا افتراض نجاح لبيانات غير موجودة. كل قسم يعلن بصراحة النطاق الزمني الذي قرأه، وإذا لم تكن هناك بيانات مسجلة في النافذة الزمنية يظهر القسم فارغًا مع رسالة واضحة «لا توجد بيانات مسجلة في هذه الفترة — التقرير لا يتضمن إلا ما هو مسجّل فعليًا على جهاز العائلة».

## 2. الطبقات المنفذة

### 2.1 طبقة النطاق (Domain) — `lib/domain/reports_domain.dart`

| النموذج | الوصف |
|---|---|
| `ReportPeriod` (week / month / custom) | الفترة الزمنية للتقرير مع نافذة كنسية `windowFor` مرتكزة على تاريخ اليوم |
| `ReportSectionKind` | أنواع الأقسام السبعة: web، usage، location، safety، modes، sos |
| `ReportSection` | قسم التقرير: مفاتيح العنوان، النافذة المقروءة فعلًا `dataStart/dataEnd`، مقياس `isEmpty` صادق |
| `ReportMetric` | مقياس رقمي مع قيمة نصية معروضة و`ReportTone` (neutral / warning / critical) |
| `ReportFormat` (pdf / csv) | صيغ التصدير المدعومة |
| `FamilyReportSnapshot` | لقطة التقرير الكاملة: العائلة، الفترة، وقت الالتقاط، والأقسام السبعة |

أُضيفت صلاحيات جديدة في `FamilyPermission`: **`viewReports`** لجميع الأدوار البالغة (الوالد الأساسي، الوالد المشارك، الزوج) و **`viewOwnReport`** لدور الطفل (يرى تقريره هو فقط)، مع تفعيلها في مصفوفات الأدوار في `family_authorization.dart`.

### 2.2 طبقة البيانات (Data) — `lib/data/reports_repository.dart`

`ReportsRepository` هو **طبقة تجميع للقراءة فقط** — لا يعدّل أي جدول من جداول الأنظمة الفرعية إطلاقًا. يتعامل مباشرة مع جداول SQLite الموجودة (الإصدار 20) دون إضافة أي جدول جديد:

| القسم | الجداول المقروءة | الاستعلامات |
|---|---|---|
| الويب | `web_hits` | إجمالي الزيارات، المحظورة، التوزيع اليومي، أفضل 10 نطاقات محظورة، التوزيع حسب الفئة |
| الاستخدام | `child_usage_summaries` + `devices` | وقت الشاشة الكلي لكل طفل (دقائق/ساعات)، أفضل التطبيقات، الأيام النشطة |
| الموقع | `location_points`، `location_alerts`، `geofences` | عدد النقاط، عدد التنبيهات، سجل التنبيهات |
| السلامة | `incidents` | عدد الحوادث وفصل الحرجة منها عن الإجمالية |
| الأنماط | `mode_activations` | عدد التفعيلات والنشطة منها |
| SOS | `sos_events` | عدد أحداث الطوارئ |

جميع الاستعلامات تستخدم نافذة زمنية صريحة (`created_at` / `blocked_at` / `day_start` / `observed_at` / `started_at` حسب طبيعة كل جدول)، وتحويل الأعمدة إلى أسماءها الصحيحة في قاعدة البيانات (مصحّحة خلال هذه المرحلة: `location_points` يُفهرس بـ `captured_at`، و`incidents` بـ `observed_at`).

### 2.3 خدمة التصدير — `lib/data/reports_export_service.dart`

| الصيغة | التنفيذ |
|---|---|
| **PDF** | `pdf` package — مستند A4 متعدد الصفحات (`pw.MultiPage`) بألوان المنصة الكحلية `#0F2A5B` والتركوازية `#00B8A9`، رأس موحد بحواف دائرية 16، جداول مقاييس وصفوف بيانات، قسم «لا توجد بيانات» مُشار إليه صراحة داخل الملف، وتذييل يوضح أن التقرير صادق ويُبنى من البيانات المسجلة فعليًا |
| **CSV** | `csv` package — ترميز UTF-8، ملفات باسم موحد `guardian_report_{familyId}_{timestamp}.{ext}` تُكتب في مجلد المستندات ويمكن مشاركتها عبر `share_plus` |

### 2.4 طبقة المزوّدين (Providers) — `lib/application/guardian_providers.dart`

| المزوّد | الدور |
|---|---|
| `reportsRepositoryProvider` | مستودع التجميع مربوط بـ `GuardianDatabase` الحقيقي |
| `familyReportSnapshotProvider(familyId, period)` | مزوّد آني (Consumer) يبني `FamilyReportSnapshot` مع معالجة الحالة الحقيقية: جاري التحميل / فشل / فارغ / بيانات، ويغيّر النافذة عند تبديل الفترة |

### 2.5 الشاشات (8 شاشات) — `lib/presentation/screens/reports_screens.dart`

| الكود | الشاشة | المسار | الوصف |

| RP-002 | `WebReportScreen` | `/reports/:familyId/web` | تقرير فلترة الويب: إجمالي الزيارات والمحظورات، أفضل النطاقات المحظورة حسب التكرار الفعلي |
| RP-003 | `UsageReportScreen` | `/reports/:familyId/usage` | تقرير الاستخدام: وقت الشاشة الكلي، الأيام النشطة، التوزيع حسب الطفل |

| RP-005 | `SafetyReportScreen` | `/reports/:familyId/safety` | تقرير السلامة: الحوادث مع فصل الفئات الحرجة |

جميع الشاشات تستخدم `FamilyRuntimeContext.can()` للتفويض، و`GuardianStateView` لمعالجة الحالات (جاري التحميل / فشل / فارغ)، ونفس نظام التصميم: كروت Material 3 بحواف دائرية 16، الكحلي #0F2A5B والتركوازي #00B8A9، خط Cairo، دعم RTL/العربية. أُضيفت مجموعة «التقارير» إلى شاشة لوحة العائلة بعد مجموعة الأجهزة.

### 2.6 التوجيه والترجمة

سُجلت 8 مسارات جديدة في `app_router.dart`، وأُضيفت **47 مفتاحًا جديدًا** (`rp_*`) في خريطة الترجمة العربية والإنجليزية بنفس نمط الإدراج المعتمد (خطاف رقم السطر)، ليصبح إجمالي المفاتيح **1131 مفتاحًا متطابقًا في كلتا الخريطتين**.

## 3. التحقق والاختبار

### 3.1 اختبارات FS-009 (10 اختبارات — جميعها خضراء)

| المجموعة | الاختبارات |
|---|---|

### 3.3 إصلاحات تكامل أنجزت خلال هذه المرحلة

اكتُشف خلال البناء أن `ReportsRepository` كان يشير إلى أسماء أعمدة غير مطابقة لواقع قاعدة البيانات (`observed_at` في `location_points` و`incidents`) وأُعيدت مواءمتها مع التعريف الفعلي للجداول، كما أُضيف صف `mode_configs` اللازم للقيود الخارجية عند بذور الاختبار، وأُتيحت حقن مجلد الإخراج في خدمة التصدير لدعم الاختبار الحقيقي دون الحاجة لـ Flutter binding.

## 4. ما لم يُنفَّذ عمدًا

التقارير المجدولة آليًا (إرسال أسبوعي تلقائي) ومؤثرات PDF العربية بخط Cairo المضمن (النصوص الحالية helvetica لاتينية مع تسميات مترجمة عبر المفاتيح) مؤجلة بوعي؛ الأول يتطلب عمال خلفية Android والآخر يتطلب تضمين خط في الأصول — كلاهما يتطلب بيئة Android حقيقية ولا ينسجم مع قرار عدم تثبيت حزم كبيرة في هذه الدورة.
