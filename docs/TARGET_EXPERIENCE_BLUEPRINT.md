# مخطط تجربة المستخدم المستهدفة (Target Experience Blueprint)

تعتمد تجربة المستخدم في منصة Guardian AI على فلسفة «الحماية المبنية على الثقة»، حيث تتوزع التجارب بين الأدوار المختلفة لتوفير تفاعل طبيعي ومريح.

| الدور (Role) | التجربة الأساسية (Core Experience) | الأهداف الرئيسية (Primary Goals) |
| :--- | :--- | :--- |
| **الأب / الأم (Parent)** | مركز قيادة ذكي وعالي الوضوح | متابعة الصحة الرقمية، رصد المخاطر، وتوجيه الإشعارات العاجلة. |
| **الطفل (Child)** | بيئة رقمية داعمة وغير جاسوسية | تعزيز العادات الرقمية السليمة، طلب المساعدة، وتفعيل الاستغاثة SOS. |
| **الشريك / الوالد المشارك (Co-Parent)** | تعاون مرن بصلاحيات محددة | مشاركة مسؤوليات الرقابة وفق سياسات أسرية متفق عليها. |

تم صياغة واجهات المستخدم بعناية فائقة لتجنب الشعور بالمراقبة المستمرة، والتركيز على التوجيه الإيجابي والتفسير البشري لتنبيهات الذكاء الاصطناعي.
