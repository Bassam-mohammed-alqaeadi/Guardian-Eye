## اختيار الشريحة الرأسية

**الشريحة المختارة: إدارة سياسة السلامة العائلية، وتشمل تعريف سياسة screen-time وbedtime/custom mode، حساب القرار الفعلي، temporary override محدود زمنيًا، وsync state.**

الاختيار يستند إلى أن نموذج السياسات ومحرك الأولوية والتخزين المحلي وoutbox موجودة بالفعل، بينما لا تزال قيمة الوالد الأساسية — ضبط حدود الاستخدام والنوم — بلا UI أو مسار Firebase/Emulator مكتمل. هذه الشريحة ذات قيمة يومية مباشرة، ولا تحتاج جهازًا أو Usage Stats لكي تثبت أن **التكوين والسياسة والمزامنة** صحيحة. في المقابل، لا يُدّعى إنفاذ مدة الشاشة أو منع التطبيقات على جهاز طفل؛ ذلك امتداد platform-dependent لاحق.

| معيار الاختيار | تقييم الشريحة المختارة |
|---|---|
| التبعية المعمارية | منخفضة المخاطر: تبني على SQLite وPolicyEngine وOutbox الموجودة بدل إدخال طبقة جديدة. |
| قيمة المستخدم | عالية: تمكن الوالد من إنشاء حدود قابلة للتفسير والاستثناء المؤقت. |
| أثر الأمان | عالٍ: التعديل محصور بالوالد/owner ويحتاج validation للوقت والجدول والـoverride. |
| قابلية Emulator | عالية: Firestore policy authorization وoutbox mutation قابلة للاختبار بلا Blaze أو جهاز. |
| جاهزية الإنتاج | متوسطة للـpolicy configuration، منفصلة بوضوح عن device enforcement. |
| تبعية الجهاز | لا توجد للشريحة الإدارية؛ enforcement الفعلي يحتاج Android physical-device لاحقًا. |

## نطاق Phase 13 المقصود فقط

1. نماذج policy schedule وvalidation صريحة وقابلة للتخزين.
2. SQLite repository لقراءة/إنشاء/تعديل/تعطيل policy والـtemporary override مع outbox.
3. Firestore event contract وrules لمسار policy داخل الأسرة، دون توسيع صلاحيات child أو cross-family.
4. واجهة parent policy manager عربية/إنجليزية تشمل loading/offline/pending/blocked/error/effective-decision states.
5. اختبارات domain/repository/widget وFirestore Emulator تؤكد owner allow وchild/cross-family deny وidempotency.
6. توثيق واضح أن Android usage enforcement وbedtime app blocking **ليسَا** ضمن دليل هذه الشريحة.

لا يدخل ضمن Phase 13: device management الكامل، child pairing redemption، FCM delivery، geofencing، filtering platform enforcement، AI model، payments، أو إعادة تصميم بيئة Firebase.
