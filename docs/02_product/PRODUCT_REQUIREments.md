# وثيقة متطلبات المنتج (Product Requirements Document - PRD)

## 1. أهداف المنتج الأساسية
توفير بيئة رقمية آمنة للأطفال مع الحفاظ على الثقة المتبادلة والشفافية الأبوية دون اللجوء إلى التجسس أو العقوبات القاسية.

## 2. الأدوار والصلاحيات في العائلة
يدعم النظام بنية عائلية متكاملة تتضمن:
- **الوالد الأساسي (Primary Parent):** إدارة كاملة للصلاحيات والعائلة.
- **الوالد / الوالدة المشاركة (Parent / Co-Parent):** صلاحيات تعاونية محددة.
- **الزوج / الزوجة (Spouse):** وضع الانسجام الأسري وإدارة مشتركة.
- **الطفل (Child):** واجهة مخصصة للرفاهية الرقمية والاستغاثة.

## 3. المميزات الرئيسية
- لوحة تحكم ذكية للأب/الأم تعرض حالة الأمان العائلي بلمح البصر.
- تقييم المخاطر بالذكاء الاصطناعي مع تفسيرات بشرية واضحة (Explainability).
- إدارة وقت الشاشة ووقت النوم.
- زر الطوارئ (SOS) والموقع الجغرافي الآمن.
